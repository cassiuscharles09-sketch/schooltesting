1. INTRODUCTION

The rapid advancement of web technologies has fundamentally transformed institutional communication and public information delivery, shifting traditional paper-based bulletins and scattered manual notices into responsive, accessible digital platforms. The DATAMEX College of Saint Adeline (DCSA) Web-Based Information System is a modern, responsive web platform developed as part of the requirements for Web System Technologies. The system serves as the institution’s primary public digital hub across all four (4) campus branches: Fairview (Main), Caloocan, Valenzuela, and Meycauayan.

Prior to the conceptualization and deployment of this platform, prospective enrollees, transferees, parents, and visitors encountered significant difficulties accessing centralized, verified school details. Information regarding program offerings, documentary requirements, campus landmarks, and DepEd voucher subsidies was fragmented across unofficial channels and physical bulletin boards. This frequently led to unprepared walk-in visits, misplaced documents, and administrative bottlenecks at campus registrar and admissions desks.

To resolve these operational challenges, the DCSA Web-Based Information System was designed and developed as a purely informational and public showcase platform. The project utilizes semantic HTML to structure comprehensive content—including academic curricula, walk-in admission checklists, and branch directories—while CSS (Flexbox, Grid, and Modern UI styling) is used to deliver interactive functions, responsive layouts, and smooth visual navigation across all devices without relying on external scripting dependencies.


2. PROJECT OVERVIEW

The DATAMEX College of Saint Adeline (DCSA) Web-Based Information System is an institutional, public-facing web platform designed to serve as the unified digital hub for prospective students, parents, transferees, and campus visitors. Operating across all four (4) major campuses—Fairview (Main), Caloocan, Valenzuela, and Meycauayan—the system bridges the communication gap between the institution and the community. Built using modern web standards, it delivers structured, reliable, and up-to-date academic information, campus directories, documentary checklists, and admission procedures accessible 24/7 on desktop and mobile devices.

2.1 System Name — DATAMEX College of Saint Adeline (DCSA) Web-Based Information System

The DATAMEX College of Saint Adeline (DCSA) Web-Based Information System is a responsive web platform designed to serve as the institution's primary informational hub for prospective students, parents, visitors, and current scholars. The system provides structured academic details, showcasing Senior High School strands, College degree programs, campus facilities, and industry accreditations across all four DCSA campuses.

It assists prospective enrollees by presenting clear walk-in admission guidelines, documentary requirement checklists, branch locations, and DepEd voucher subsidy information during official school office hours from 8:00 AM to 5:00 PM. Furthermore, the system serves as a centralized source for official uniform dress code references, facility overviews, and direct inquiry channels. Designed for seamless access on both desktop and mobile devices, the web system improves information transparency and enables applicants to prepare all required documents before personally visiting their chosen campus branch.

2.2 System Description and Operation

• What the System Does:
The system serves as an interactive informational portal that presents all essential institutional data in one organized environment. It showcases CHED-recognized collegiate programs (BSIT, BSHM, BSBA, ACT) and DepEd-recognized Senior High School strands (STEM, ABM, HUMSS, TVL-ICT, TVL-HE). It provides complete walk-in admission requirements, guidelines on the 100% DepEd Senior High School Voucher subsidy, student dress code and uniform references, facility showcases (computer laboratories, culinary kitchens, libraries), verified campus hotlines, and an interactive public inquiry channel.

• How It Works:
The platform operates entirely on client-side web technologies utilizing standards-compliant HTML for semantic page structure and modern CSS (Flexbox and Grid) for responsive layouts. Users navigate seamlessly across dedicated sections through a responsive header menu equipped with a mobile-friendly CSS navigation toggle and smooth-scrolling anchors. When visitors access the site, they can readily inspect specific branch profiles (addresses, landmarks, and embedded map locations), view step-by-step enrollment instructions, verify required entrance credentials, and utilize the built-in inquiry form to formulate direct questions before visiting the campus in person. The system requires no external database or complex client-side scripting dependencies, ensuring ultra-fast page rendering and universal compatibility across all modern web browsers.

2.3 Problem Statement

Prior to the development of the system, DATAMEX College of Saint Adeline (DCSA) faced recurring communication and operational challenges across its four branch campuses:

1. Unprepared Walk-In Applicants: Prospective students frequently arrived on-site missing mandatory enrollment documents (such as Form 138 / Report Cards, Certificates of Good Moral Character, and PSA Birth Certificates), resulting in delayed evaluations and repeated, inconvenient trips to the campus.

2. Multi-Branch Information Fragmentation: Because school information was dispersed across unofficial social media pages, word-of-mouth, and physical bulletin boards, parents and applicants experienced confusion regarding which specific degree programs or SHS strands were active per branch, as well as uncertainty surrounding correct campus office hours (8:00 AM – 5:00 PM).

3. Voucher Subsidy Ambiguity: Many incoming Senior High School enrollees lacked clear, official guidance on the eligibility and coverage of the 100% DepEd Voucher Program, leading to hesitation and enrollment delays.

4. Administrative Bottlenecks: Front-desk personnel and registrar staff were overwhelmed by repetitive basic inquiries (e.g., location directions, uniform policies, and documentary requirements), pulling valuable staff hours away from processing official student records and on-site applications.

2.4 Proposed Solution

To address and resolve the identified challenges, the DCSA Web-Based Information System introduces a centralized, reliable digital solution:

1. Pre-Admission Preparation Hub: The system provides transparent, structured documentary requirement checklists and clear walk-in guidelines. This guarantees that applicants have all official credentials organized before personally reporting to the admissions desk, effectively cutting registration delays.

2. Unified Branch Directory & Geolocation: The platform organizes all four campuses (Fairview, Caloocan, Valenzuela, and Meycauayan) with verified contact hotlines, official email addresses, landmark guides, and Google Maps integration, eliminating multi-branch confusion.

3. Transparent Academic & Voucher Showcase: It delivers comprehensive curriculum highlights for both College and Senior High School offerings, prominently displaying the guidelines for the 100% DepEd Senior High School Voucher subsidy so families can make informed enrollment decisions.

4. Streamlined Institutional Showcase & Reduced Staff Burden: By providing access to official uniform standards, facility previews, and structured inquiry messaging channels, the web platform resolves repetitive inquiries automatically. This enables front-desk staff to focus on fast, efficient on-site application processing.


3. PROJECT GOAL AND OBJECTIVES

3.1 Project Goal

The main goal of this project is to develop a responsive, web-based Information and Public Showcase System for DATAMEX College of Saint Adeline (DCSA) using pure HTML and CSS that provides students, parents, prospective applicants, and visitors with easy, centralized access to vital institutional information, such as academic programs, walk-in admission guidelines, campus directories, facilities, and uniform standards across all four DCSA branches.

3.2 Specific Objectives

1. Centralized Academic Showcase: To structure and showcase CHED-approved collegiate programs (BSIT, BSHM, BSBA, ACT) and DepEd-recognized Senior High School strands (STEM, ABM, HUMSS, TVL-ICT, TVL-HE).

2. Walk-In Admission Preparation: To provide prospective students with complete walk-in enrollment checklists, documentary requirements, and voucher subsidy information to streamline on-site processing.

3. Campus Location & Navigation Assistance: To organize verified branch addresses, landmarks, Google Maps integration, and social media channels for all four DCSA campuses (Fairview, Caloocan, Valenzuela, and Meycauayan).

4. Student Life & Uniform Guidelines: To provide a visual dress code policy and uniform guide for male and female students to foster campus discipline.

5. State-of-the-Art Facilities Presentation: To showcase campus computer laboratories, culinary arts facilities, and academic resource libraries in a modern 16:9 alternating split layout.

6. Direct Inquiries & Communication: To deliver verified campus contact hotlines, email directories, and responsive inquiry messaging forms.
